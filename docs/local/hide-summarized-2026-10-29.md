# 一键隐藏已总结楼层 · 2026-10-29

本轮版本为 Memory 1.0.14，基于 1.0.13 增加此按钮。

在“楼层管理”的“恢复全部楼层”旁增加“隐藏已总结楼层”。按钮即时读取当前世界书的总结进度 N，执行 `/hide 0-(N-1)`，上限为当前聊天实际长度；不依赖 DOM 是否渲染，不改变后续消息已有的隐藏状态，不修改自动隐藏开关。

空聊天、无世界书或进度为 0 时提示而不执行；读取过程中切换聊天、发生归档回溯则取消。按钮执行期间禁用，错误提示后恢复可用。原有恢复全部及手动范围操作保留。

验证：113 项 Node 测试通过，新增范围边界、未渲染数据、进度实时更新、空数据、设置不变、聊天切换及回溯中止、读取失败等用例。320 / 375 / 1280 浏览器模拟实际点击新按钮、恢复全部、手改世界书进度后再次隐藏通过；按钮同组可见、不溢出，无页面错误。模拟未访问真实用户数据。

主要文件：assets/memory-summary/summary.html、ui/bindings.js、core/autoHideManager.js、personal/workspace.js。新增验证 personal/tests/hide-summarized.test.mjs、personal/dev/check-hide-summarized.cjs。
