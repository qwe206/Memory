# 恢复原归档条目

按用户要求，恢复总结时直接启用选中的原归档条目，不再为带有剧情快照的归档复制新条目。条目的键与 UID 保持不变，恢复后后续总结继续写入它。

如同一本世界书中已有另一条启用的总结，先在该条目上归档并停用，再启用选中的原条目。不会删除用户已有条目或清理以前版本生成的副本。

恢复成功后移除条目上的旧归档快照；下次归档重新捕获最新的总结、向量绑定和楼层状态。剧情绑定的恢复机制保留，跨聊天恢复仍按照归档时的向量选择恢复。

保存或楼层恢复失败时，撤回世界书和绑定状态，原归档保持停用并可重试。

验证：117 项 Node 测试通过。覆盖原条目编号不变、跨聊天恢复、连续三轮归档恢复、恢复后列表不再包含该启用条目、再次点击不产生条目、已有另一条启用总结、保存失败与楼层恢复失败的回滚及重试。旧版归档恢复测试仍通过。

发布版本：1.0.16。
