# Memory

面向 SillyTavern 的聊天记忆插件。当前版本：1.0.0。

## 安装

在酒馆的扩展管理中使用以下仓库地址安装：

`https://github.com/qwe206/Memory`

安装后刷新页面，在顶栏点击 Memory。升级时通过酒馆扩展管理更新。
迁移前请导出聊天、世界书和配置作为备份，并停用之前的记忆插件实例，避免重复监听和写入。

## 功能

- 大小总结、批量与自动总结、预览编辑、静默模式。
- 世界书选择、连续总结、归档恢复、楼层隐藏与本地备份。
- 向量知识库、分块检查、检索与重排序。
- API 配置组、模型选择、连接测试与提示词设置。
- 手机布局、主题切换与独立工作区。

每次大总结仅合并新的小总结。保留的历史大总结在向量写入并回读成功后才移出历史区。
兼容已有单条目总结世界书；遇到损坏或分段条目时不会自动删除原文。
旧数据标识仅供兼容读取，新的插件名称与入口统一为 Memory。
配置会在首次启动时从当前浏览器已有的旧实例复制；浏览器本地数据和外部密钥仍需在目标环境确认。

## 开发与验证

```sh
npm ci
npm test
node personal/dev/server.mjs
```

开发预览使用模拟酒馆主机、API 和授权状态；正式安装保留原有授权模块。
